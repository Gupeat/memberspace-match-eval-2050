# Reviewer checklist - rework v2

Repository: https://github.com/Gupeat/memberspace-match-eval-2050

This checklist maps each review item to a committed artifact in the repository.

## 1. Public code repository (blocker)

- Source: match_eval/ (dataset, filters, scoring, metrics, evaluate, report, cli).
- Tests: tests/ (55 tests, including one dedicated file per metric).
- Data: data/companies.json (40), data/supplies.json (30, 27 active), data/demands.json (60, 8 types), data/ANNOTATION.md.
- Run/test instructions: README.md and REWORK.md.

## 2. Dataset + annotation + stats (major)

- data/ANNOTATION.md documents the synthetic labeling rules and limitations.
- Command: python -m match_eval stats
- Output: companies 40, supplies 30 (active 27), demands 60, demand_type_count 8.

## 3. Metric unit tests (major)

- Dedicated files: tests/test_metric_hit_at_5.py, tests/test_metric_ndcg_at_10.py, tests/test_metric_filter_violations.py, tests/test_metric_rationale_trace.py, tests/test_metric_top5_concentration.py (14 tests).
- Supporting suites: tests/test_metrics.py, tests/test_filters.py, tests/test_scoring.py, tests/test_evaluate.py, tests/test_cli.py, tests/test_dataset.py, tests/test_report.py.
- Full suite: 55 passed.
- Command: python -m pytest tests
- Full log: artifacts/ACCEPTANCE.md and artifacts/ac-round1.log, artifacts/ac-round2.log.

## 4. Non-zero exit code on violations (major)

- tests/test_cli.py asserts exit code 2 when hard-filter violations are present and exit code 3 when NDCG@10 regresses by more than 2 points.
- Diagnostic run record: artifacts/diagnostic-no-filter.md (265 violations, exit 2).
- Normal run: exit 0 when violations are zero.

## 5. v1/v2 comparison report (major)

- Committed report: artifacts/report-compare.md.
- Linked from README.md.
- Generated by: python -m match_eval compare --weights-a v1 --weights-b v2 --report artifacts/report-compare.md
- PR #1 (merged) is the requested PR trail for this rework: https://github.com/Gupeat/memberspace-match-eval-2050/pull/1

## 6. Honest limits

- The 60-demand labels are rule-generated synthetic fixtures, not human annotations.
- The v2 weights equal the annotation formula, so v2 NDCG@10=1.0 is a construction ceiling, not a generalization result.
- See docs/EVALUATION-LIMITS.md.

All data is synthetic; no real company, contact, API key or PII is included.
