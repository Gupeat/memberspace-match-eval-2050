This repository is the complete, public, reproducible delivery for ClawHunt task #2050.
It replaces the previous filebin-only submission that could not be opened or verified.

## Blocker / major items

1. Code repository - all source, tests, data and reports are here; README.md documents run and test commands.
2. Dataset + stats - data/companies.json (40), data/supplies.json (30, 27 active), data/demands.json (60, 8 types) and data/ANNOTATION.md; run "python -m match_eval stats" to reproduce the counts.
3. Metric unit tests - one dedicated file per metric: tests/test_metric_hit_at_5.py, tests/test_metric_ndcg_at_10.py, tests/test_metric_filter_violations.py, tests/test_metric_rationale_trace.py, tests/test_metric_top5_concentration.py; plus tests/test_metrics.py and the integration suites. "python -m pytest tests" reports 55 passed.
4. Exit-code test - tests/test_cli.py asserts a non-zero exit for hard-filter violations and for an NDCG@10 regression greater than 2 points; artifacts/diagnostic-no-filter.md records the --no-hard-filter diagnostic run.
5. v1/v2 comparison report - artifacts/report-compare.md is committed and linked from README.md; it is generated by "python -m match_eval compare --weights-a v1 --weights-b v2 --report artifacts/report-compare.md".

All data is synthetic; no real companies, contacts or PII are included.
